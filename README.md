# theyoge.github.io

Personal portfolio & security writeups for Yogender Singh.

## Adding a writeup

Create a new Markdown file in `_posts/` named `YYYY-MM-DD-slug.md` with this header:

```yaml
---
layout: post
title: "My Writeup Title"
date: 2026-10-20
tags: [web, api, xss]
description: "One-line summary shown in the list."
---
```

Write the rest in Markdown. Push, and GitHub Pages publishes it automatically.
